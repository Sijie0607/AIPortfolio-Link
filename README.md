# AI Portfolio Website

A personal portfolio website designed and developed through an AI-assisted workflow using Claude, Google AI Studio, and Cursor.

Live site:
https://ai-portfolio-link.vercel.app/

---

## Overview

This project explores how generative AI tools can assist the design and development of a complete web experience.  

The website presents my projects in data analysis, research, and creative work, while also serving as an experiment in AI-supported interface design and coding workflows.

The interface combines interactive elements, motion design, and responsive layouts to create a narrative-style portfolio experience.

---

## AI-Assisted Development Workflow

This project was built using a combination of AI tools and manual refinement.

**Claude**
- Used for generating UI prompts and structuring design concepts
- Assisted in drafting interface logic and content structure

**Google AI Studio**
- Used to prototype interface layout and component structure
- Helped translate conceptual UI prompts into usable design directions

**Cursor**
- Used for implementing and refining the codebase
- Assisted in debugging, animation adjustments, and structural improvements

The development process involved iterative collaboration between AI-generated suggestions and manual design decisions.
